プライバシーポリシー

出張Base(TripBase) / 最終更新日: 2026年8月1日

出張Base(以下「本アプリ」)は、開発者(以下「当方」)が個人開発しているiOSアプリです。本ポリシーは、本アプリの利用者(以下「ユーザー」)の情報の取り扱いについて説明するものです。

1. 本アプリが収集する情報

本アプリは、ユーザーのアカウント登録を必要とせず、利用にあたって個人情報の入力を求めることはありません。

ユーザーが入力する出張の日程・宿泊先・持ち物リスト・書類・メモ・タスク・日当設定などの情報は、すべてユーザーの端末内にのみ保存され、当方を含む第三者のサーバーに送信・保存されることはありません。

本アプリは、広告表示、アクセス解析(アナリティクス)、ユーザーの行動追跡(トラッキング)を一切行いません。

2. 外部サービスとの通信

本アプリは、以下の目的でインターネット通信を行いますが、いずれもユーザーを特定できる情報(氏名・メールアドレス・端末識別子など)は送信しません。

目的通信先送信される情報
天気予報の取得Open-Meteo (open-meteo.com)出張先として登録した都市名
為替レートの取得open.er-api.com通貨コードのみ
現地の祝日情報の取得Nager.Date (date.nager.at)国コードと年

これらは無料の公開APIであり、当方が管理するサーバーではありません。各サービスの通信内容については、各サービス提供元のプライバシーポリシーもあわせてご確認ください。

3. 端末内に保存される情報

以下の情報は、Appleの標準的な端末内データベース機能(SwiftData)を使い、ユーザーの端末内にのみ保存されます。

  • 出張の日程・目的地・宿泊先情報
  • 持ち物チェックリスト
  • 書類の登録情報(名称・番号・有効期限・メモ)、および任意で添付した画像・PDFファイル
  • タスク・メモ
  • 日当計算の設定・履歴

これらの情報は、ユーザーが本アプリをアンインストールするか、設定画面から「すべてのデータを削除」を実行することで削除できます。

4. 通知(プッシュ通知)

本アプリの「出発前リマインダー」機能を有効にした場合、端末のローカル通知機能を使用して通知を送信します。この通知はユーザーの端末内で処理されるものであり、外部サーバーを経由しません。通知の許可は端末の設定からいつでも変更できます。

5. 写真・ファイルへのアクセス

書類に画像やPDFを添付する場合、iOSの標準機能(フォトピッカー・ファイルピッカー)を使用します。これらの機能は本アプリのプロセス外で動作するため、本アプリが写真ライブラリ全体にアクセスすることはなく、ユーザーが選択したファイルのみが本アプリ内に保存されます。

6. 第三者への情報提供

当方は、ユーザーの情報を第三者に販売・提供することはありません。

7. 本ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更されることがあります。重要な変更がある場合は、本アプリ内でお知らせします。
